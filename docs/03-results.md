## Independent critic

### Round 1

A fresh agent was given the frozen candidate and the acceptance criteria, but not the builder's reasoning. It found **no critical failure**, and independently confirmed:
- the goldens are byte-identical when regenerated from upstream
- profile on/off behaves as claimed
- every boundary escape it tried was denied
- modified upstream tests were changed only as much as the behavior change required
- AGPL license and attribution are untouched

It confirmed six defects, **all fixed** in `f9f76ff`:

| # | Finding | Fix |
|---|---|---|
| 1 | SVG figures could read local images by absolute path (upstream code path, outside the boundary) | `stripExternalRefs` + CSP on the fallback page; end-to-end pixel test |
| 2 | Checker false positives ("stopping power", "need to go over", "excellent resolution", URL + full stop) and false negatives (prose question stacks, "great job", colon-less MRN, patient advice); steers split turns | Patterns rewritten; 6 regression tests; unknown guideline IDs listed for a hand check |
| 3 | `profile.ts` silently replaced a malformed `settings.json` | Refuses, changes nothing; test |
| 4 | Prober not covered on the real request path | Scenario S0b |
| 5 | Three profile clauses pulled against practice doctrine | Explicit practice deferrals; tests pin them |
| 6 | Boundary created the study folder on every call | Removed; test |

Not fixed: `ls` shows whether a symlink's target is a directory. This leaks one bit, never contents.

## Known limitations

- **The problem's committed solution is in the browser payload** (upstream design): the practice UI never renders it before conclude (upstream test `render-practice-surface`), but it's visible in DevTools. Fixing that would change upstream's view contract, so it's out of scope for a 5% fork.
- **The reference video couldn't be reached** from this environment (YouTube blocked by the proxy, no transcript found). The build rests on the repository alone.
- **The cost meter in the screenshots** (e.g. "$0.0023") is upstream's estimate for the configured model ID applied to scripted turns. No API call was made.
- **The study folder defaults to `<data dir>/study`.** In the desktop app that's inside the app's data directory, so set `LH_STUDY_DIR` to a folder you use.
